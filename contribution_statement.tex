\section{Detailed Breakdown of Contributions across Core Dimensions}

\subsection{1. TITA NOVIANA (Student ID: 24120500011)}
\textbf{Role:} Lead Data Engineering \& Econometric Modeling
\begin{itemize}[leftmargin=1.5em, itemsep=0.2em]
    \item \textbf{Analytical Contribution:} Formulated the foundational predictive questions and research hypotheses ($H_1, H_2, H_3$); designed the causal chronological expanding-window walk-forward validation framework; performed statistical stationarity audits (Augmented Dickey-Fuller tests) and cross-correlation function (CCF) lag diagnostics.
    \item \textbf{Coding \& Implementation:} Engineered automated data pipelines for SEC EDGAR XBRL companyfacts API and FRED Federal Reserve macroeconomic series (\texttt{pull\_edgar.py}, \texttt{pull\_fred.py}); implemented chronological panel feature lagging with strict zero-leakage controls (\texttt{build\_panel.py}); programmed the Naive Persistence Baseline and AR(1) ARIMA maximum-likelihood models.
    \item \textbf{Interpretation Contribution:} Evaluated baseline persistence dynamics versus autoregressive econometric models; interpreted the downward life-cycle drift in hyperscaler growth rates; analyzed sample size constraints and standard error bounds.
    \item \textbf{Presentation \& Defense:} Delivered Presentation Pitch Sections 1 \& 2 (Business Problem Context, Capital Allocation Stakeholder Dilemma, & Zero-Leakage Data Pipeline Architecture); prepared for Technical Interview inquiries on data auditing and time-series stationarity.
\end{itemize}

\vspace{0.4em}
\subsection{2. SUCI FRANSISCA SISILIA R (Student ID: 24120500008)}
\textbf{Role:} Lead Machine Learning \& Hyperparameter Tuning
\begin{itemize}[leftmargin=1.5em, itemsep=0.2em]
    \item \textbf{Analytical Contribution:} Designed the systematic hyperparameter search spaces for the two primary non-baseline models (Regularized Linear and Gradient Boosted Trees); established expanding-window \texttt{TimeSeriesSplit} cross-validation protocols to prevent temporal data contamination; evaluated shrinkage mechanics in ill-conditioned financial panels.
    \item \textbf{Coding \& Implementation:} Developed regularized Ridge ($L_2$) and Lasso ($L_1$) estimators with dynamic regularization path optimization; implemented the XGBoost Regressor with shallow-tree constraints (\texttt{max\_depth=2..3}); generated comprehensive model evaluation tables (RMSE, MAE, Directional Accuracy) and diagnostic visualization plots.
    \item \textbf{Interpretation Contribution:} Conducted the Default-versus-Tuned comparative performance audit required by the rubric; interpreted Lasso coefficient shrinkage to zero ($0.000$) for all lagged capex features; synthesized empirical evidence disproving the multi-quarter capex predictive hypothesis.
    \item \textbf{Presentation \& Defense:} Delivered Presentation Pitch Section 3 (Candidate Model Benchmark, Default vs. Tuned Performance Trade-offs, & Non-Causal Feature Interpretation); prepared for Technical Interview questions regarding hyperparameter search spaces and regularization.
\end{itemize}
